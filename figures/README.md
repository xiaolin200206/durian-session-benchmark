## Caveat on Fig. 5 — must be fixed before submission

The per-class precision, recall and support of Table 8 determine **23 of the 25** confusion cells
exactly. Two off-diagonal cells are underdetermined: the single Phomopsis error and the single
pink-disease error are distributed one each between the algal and leaf-rot columns, and the
per-class metrics do not say which way round. Both are marked with an asterisk in the current
figure.

Replace them from the true matrix before submitting:

```bash
python export_confusion.py --ckpt <seed42_checkpoint> --split_dir clean_split --out confusion_seed42.csv
```

then edit the `M` array in `fig5()` of `make_paper_figures.py` and remove the `amb` set and its
footnote.
